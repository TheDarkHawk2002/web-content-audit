# Webinhalte strukturieren

Ein kleines CLI prüft lokale Markdown-Inhalte auf fehlende Metadaten, defekte interne Links und doppelte Slugs.

## Zielumfang

- Kleines, allgemein gehaltenes Konsolenprojekt.

## Startpunkt

Siehe `src/`. Das Gerüst enthält noch keine fertige Implementierung.

## Geplante Bereiche

- Eingabe prüfen und verständliche Fehler ausgeben
- Kernlogik klein und testbar halten
- Bericht oder lokale Speicherung ergänzen
